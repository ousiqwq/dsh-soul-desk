# 本地界面修正

2026-11-12。按用户后续反馈实施，**本轮不推送 GitHub、不发布 npm**。

- Soul Desk 本地版本：`0.4.1-local.2`。
- 对话顶部使用 DSH 原生 ghost 按钮；保留当前人设与子代理两组信息，取消常驻底色、外框和阴影。
- 设置页只提供全局与工作区。会话规则继续持久保存、优先解析，但只从对话顶部菜单编辑。
- 工作区选择框在两个范围下都保留原位；选全局默认时使用原生禁用样式置灰，切工作区后启用，保留上次所选工作区。
- 工作区选择框收起时仅显示名称。展开选项显示名称和路径；路径采用 11px、淡色、可换行的注释样式。
- Team Desk 设置与关系图中的人设显示为只读，提示到对话顶部修改。本机使用 `0.10.1-local.1`：从当前安装包提取，仅替换 PersonaBinding 组件、补充其双语提示和本地版本号；其余文件逐字节保留，避免混入另行开发的功能。

验收包含：31 项自动测试、原生浏览器实际点击与刷新、中英文切换、深浅主题、五档宽度、菜单路径字体及收起高度、透明/零边框/零阴影的计算样式、Team Desk 设置无会话人设选择器。测试数据只存在于独立 DSH_HOME。

本地记录：`test-results/native-host/reports/browser-local.json`、`team-readonly.json`、`test-results/deployment-local-ui.json`。安装前再次保存完整 DSH_HOME 及 profile、人设库、原生会话摘要清单；会话人设和子代理选择、工作区规则、全部人设与记忆均核对保留。

此前已提交发布的 `0.4.0` 保持原版本；本地修正尚未同步到远端。

本次扩展功能验收已通过完整 DSH 实际模型请求中的三层规则、A/B 人设及记忆切换、真实记忆工具归属、none/follow、三种注入模式、总开关、子代理策略和冷恢复。相关报告在 `test-results/native-host/reports/native-api.json`、`native-resume.json`；布局验收记录五种宽度下切换前后的卡片高度及控件位置。

五档布局检查（320 / 390 / 650 / 900 / 1440）中，全局与工作区卡片高度逐一相等，选择框位置保持一致。浏览器从对话菜单切到 B、再切到 C 后，实际模型请求中的人设和记忆标记分别匹配，未混入旧人设。当前安装记录见 `test-results/deployment-fixed-picker.json`。
