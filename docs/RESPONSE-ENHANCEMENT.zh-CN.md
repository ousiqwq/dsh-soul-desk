# 提示词增强

在私人灵魂设置中提供**默认关闭的全局开关**，右侧的**高级设置**使用 DSH 原生窗口。开关独立于原有的人设总开关；开启或关闭从下一次模型请求生效，不修改历史消息。

## 行为

- **注入内容**：默认注入上游 `dsh-unrestricted` 的执行模式正文，10246 字符，按字节保留。原文与四个结构锚点集中在 `upstream-prompt.js`，每条附 `sha256`，与随包内置的上游 `src/rules.js` 比对。
- **没有包装层**：不添加标题、摘要或额外边界句。默认设置下 `renderEnhancementPrompt()` 直接返回正文。
- **三项可选要求**：简洁开场、完整交付、保留用户命名。默认关闭；开启后追加在正文之后，不改动正文本身。
- **子代理**：可单独设置是否应用增强，不改变子代理的人设继承规则。
- **人设与记忆**：原有人设与个人记忆段落从不被改写，增强段独立加入。上游正文声明外部人设不得收窄其内容尺度，两者并存而非一方覆盖另一方。
- **原生机制不变**：PTC 执行协议、SDK、工具目录、Plan 规则、审批、沙箱和结构化输出报告仍由宿主决定。正文自身也声明不改变这些机制。
- **编辑**：可编辑、预览、保存或恢复默认草稿。保存不会开启开关，恢复默认只改草稿。跨页面同时编辑时拒绝过期写入，并保留当前草稿供手动合并。

## 配置

设置单独保存在 `$DSH_HOME/private-soul/prompt-enhancement.v1.json`，最近十次修改前的版本位于 `enhancement-backups/`。初次安装和读取不会创建配置；人设存档导入导出、记忆整理均不改动它。

格式损坏时仅关闭增强，不覆盖原文件，不影响原有人设与记忆。检测到独立安装的 `dsh-unrestricted` 段时跳过注入，避免重复；仅按段落名判断。

## 边界

增强是模型指导，不增加工具权限，也不保证模型每次都遵循文风要求。优先、替换和追加三种人设方式均受支持。移植范围与结构差异见 [上游迁移说明](UPSTREAM-INTEGRATION.md)。
