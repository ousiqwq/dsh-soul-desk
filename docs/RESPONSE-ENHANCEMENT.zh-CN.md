# 提示词增强本地验收

历史验收版本：0.5.0-local.1；验证宿主：DSH 0.2.2-rc.2。此记录随当前 GitHub 源码同步，npm 未更新。

- 默认关闭的独立全局开关，右侧为原生高级设置窗口。
- 可选择简洁开场、完整交付、保留命名、是否应用于子代理，并编辑、预览、保存新增提示词。保存不会开启开关，恢复默认只改草稿。
- 原有人设、个人记忆及原生 PTC/Plan/结构化输出约定明确保持优先。原段落和工具 schema 不改写。
- 配置与 library.json 分开持久化，支持修订号冲突保护和十份滚动备份。损坏时仅关闭增强，保留原文件。

## 已完成验证

1. 42 项自动测试通过，包括四模式 × 三种人设方式的提示词矩阵、默认关闭、按字面保留模板、幂等注入、子代理排除、独立模块检测、读取不写盘、配置损坏、并发冲突、权限及 API 来源校验。
2. 真实 DSH 隔离实例验证 standard、ptc、minimal、cordis 四模式；每种模式均检查优先、替换、追加及增强开关。子代理增强可以独立关闭，不改变人设派生。
3. 真实执行器验证 PTC 嵌套的 Skill 完整读取、私人记忆和 MCP 调用；禁用能力仍被隐藏并拦截。File Bridge 二进制下载和来源校验仍通过。
4. 浏览器验证中英文实时切换、明暗主题、320/390/1440 宽度及 320×700 矮屏、前景命中、内部滚动、可见保存按钮、Escape 与焦点恢复、独立草稿、预览不落盘、保存不启用和过期写入恢复。
5. 原有人设编辑、记忆编辑及版本、筛选、存档导出与合并导入通过；重启恢复及嵌套子代理人设隔离通过。
6. 当前 DSH 安装后保持默认关闭；原 library.json 字节未变，其他插件依赖、bundle 顺序和宿主配置未变。当前页面另做只读窗口验收。

隔离实例使用合成模型和合成数据；以上验证组装、持久化和工具执行契约，不保证所有外部模型每次都遵循文风提示。配置和固定保护说明为提示词指导，运行权限仍由 DSH 原生机制负责。

## 真实模型补测

使用当前 DSH 配置的 `example-provider / example-model` 端点，进行了四次无工具、无生产会话的独立请求。测试使用已安装版本的提示词生成器及合成人设、记忆，没有加载用户真实的人设内容。

- 基线：人设前缀与合成记忆正常，不出现新增测试标记。
- 自定义增强：加入的测试后缀实际出现在回答中，同时保留原有人设前缀与记忆答案。
- 默认增强：算术样例给出简洁结果并保留人设称呼。
- 默认增强：PowerShell 脚本样例保留给定路径、名称和值，包含 JSON 转换和文件写入，未谎称已实际执行。

四例均通过。原 library.json 和生产增强开关、修订号均未改变。完整合成输入、输出及检查结果保存在本机忽略目录 `operations/enhancement-20261115/real-model-check.json`。

这属于小样本行为验证，不是统计效果对比。基线本身也能完成一般任务，不能由此推导出增强的普遍提升幅度。原项目完整提示词并未安装，因此没有对原版“无条件执行／绕过限制”宣称作出验证。
