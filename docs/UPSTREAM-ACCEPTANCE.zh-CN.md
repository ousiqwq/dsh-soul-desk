# 上游框架迁移验收

本地版本：`0.5.0`。宿主：DSH Web `0.2.2-rc.2`。原项目：[dsh-unrestricted](https://github.com/yexi-by/dsh-unrestricted)，MIT。框架基线 0.2.8，提交 `1383c6c16849a0f05bb8f9d927aa1bb31d772547`；提示词原文取自 0.2.9，提交 `c7afd4e03d162cf9545f47168f29a5ec225c0bd0`。两个版本的 `src/rules.js` 逐字节相同。

## 迁入范围

- 原项目的结构段落融合机制、Standard/PTC/Cordis/Minimal 适配、Minimal 作用域覆盖及模式切换/关闭/销毁清理。
- PTC、Plan、结构化输出协调；按模式诊断、重新检查、最近真实组装与独立模式完整预览。
- 保留默认关闭、高级效果开关与提示词编辑、独立配置、修订冲突检测及备份。
- Soul 原有三层人设规则、记忆、子代理选择不改动。人设与记忆段按原文保留，不被增强段改写；上游正文声明外部人设不得收窄其内容尺度，两者并存而非一方覆盖另一方。
- 为当前 DSH 的 complete 段恢复行为及 Soul 现有后处理增加保护收尾；未知结构或增强失败时回退。

原项目的提示词原文已按字节迁入 `upstream-prompt.js`：执行模式正文 10246 字符，人设指针 170 字符，Plan 追加 349 字符，PTC 追加 400 字符，结构化输出追加 138 字符，另含四个结构锚点。默认设置下 `renderEnhancementPrompt()` 返回的正文与上游完全一致，不添加包装标题、摘要或额外边界句。每条文本的 `sha256` 记在 `UPSTREAM_SHA256`，由 `tests/upstream-prompt.test.mjs` 与随包内置的上游 `src/rules.js` 原文比对。

框架仍是适配集成而非逐字节复制：上游把追加文本直接挂到人设旁的既有段落，我们插入独立的 `private-soul:response-enhancement` 段，以便独立编辑、预览和关闭。注入内容相同，段落名与插入位置不同。模型是否遵循这些文字取决于模型本身，源码一致不等于行为等价的实证。详见 [范围说明](UPSTREAM-INTEGRATION.md)。

## 验证结果

1. 56 项自动测试通过（含 4 项上游原文逐字节回归），结构融合、幂等、字面模板、私人段保护、真实 Cordis 流水线、Minimal 覆盖和自定义角色、关闭与销毁、无模式列表的宿主推断、空配置与故障回退、独立模块共存、只读预览、并发冲突及 API 来源校验。人设指针在优先、替换、追加三种方式下均落到实际承载人设的段落，重复装配不重复注入。
2. 隔离 DSH 的四模式 × 三种人设注入方式，增强开关前后均通过；工具 schema 与个人记忆注入保留。
3. 空白会话在 Standard、Minimal、PTC 间实际切换，确认走 `minimal-scope-shadow` 路径。关闭后临时覆盖和增强规则清除。原生 Plan 模式与 PTC 协调通过。
4. 合成模型驱动真实执行器：PTC 嵌套的 Skill 完整读取、记忆与 MCP 调用通过；禁用能力仍被隐藏并拦截。File Bridge 二进制下载回归通过。
5. 四模式完整预览、重新检查无模型调用、无配置写入；当前状态与人设文件不变。完整预览能保留字面 `{{...}}`。
6. 中英文、明暗主题、320/390/1440 宽度、矮屏滚动与固定页脚、人设草稿和冲突处理通过。异步预览和状态轮询未造成滚动回跳。
7. 原有人设编辑、记忆版本与筛选、存档导出及合并、原会话和嵌套子代理恢复通过。冷启动的旧子代理先按原生顺序恢复父会话。
8. 真实模型补测使用当前配置的 `example-provider / example-model`，处理隔离 DSH 新框架组装的完整提示词。自定义后缀及脚本路径、字段、JSON 写入样例均通过。仅使用合成人设、记忆，无工具或生产会话调用。该补测在提示词原文迁入之前执行，验证的是当时可编辑的交付指导，不是上游原文的效果对照。
9. 已安装当前 DSH 并实点原生高级窗口，四模式重新检查通过。原 library.json 和已有增强设置字节一致，其他依赖、bundle 顺序及宿主配置未变，默认仍关闭。

运行日志、合成样例输出、截图、包校验值及安装前备份保留在本机忽略目录 `operations/native-fusion-20261115-091508/`，不进入发布包。

此历史验收记录随当前 GitHub 源码同步。当前版本 `0.5.0` 已推送 GitHub 并发布到 npm（`latest`），新增上游提示词原文、逐字节回归测试及人设指针锚定修正。
