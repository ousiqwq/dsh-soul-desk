# Soul Desk 0.4.0 验收记录

2026-11-12。完整运行验收基于 DSH 0.2.2-rc.2、Node.js 26。使用独立 DSH_HOME、合成人设/记忆及本地脚本模型，不调用付费模型，不将真实会话或人设放入公开仓库。

## 实现

- 自身人设与派出子代理策略均支持全局、工作区、会话三层规则；明确的会话选择优先，none 停止继承。
- 一个原生 DSH Menu 同时管理两组选择，按钮显示当前人设和子代理策略；设置页使用原生 Button、Input、Switch、SegmentedTabs 与语义色值。
- 原生 agent/created 在首轮模型请求前保存派生决定；提示词装配和记忆工具共用本轮归属。后续更改父会话不改写现有子代理。
- schema v3 保留人设 ID、个人记忆及明确会话绑定；迁移前原文件逐字节备份。保留 `/private-soul/v2` 与 session-select 兼容接口。
- 删除或清空所选人设不会自动选择另一人设。保存新草稿或 merge 导入不会覆盖明确的全局 none。

## 限制与回滚

- native fork 仍复制父会话已有历史。停止新的 Soul 注入不会清除历史中已出现的私人信息；需要不带历史时用 fresh spawn。
- 外部 ACP 后端没有经过提示词控制验收；不声明对其生效。
- 完整运行与浏览器验收使用当前 rc.2；旧版兼容由版本矩阵自动测试核对。
- profile 内旧 rc.5 间接依赖的 Cordis peer 提示仍存在；本次未扩大范围升级其他插件依赖，完整宿主检查已通过。
- 回滚必须成套恢复升级前的插件 profile 和 private-soul 数据，不能让旧插件读取 v3。当前安装已保留完整 DSH_HOME 压缩备份、原 profile、人设库及会话摘要清单。

Team Desk 的最小来源显示适配另存为 [兼容补丁](../integrations/team-desk-0.10.0-soul-v3.patch)，已应用到本机安装；普通 Soul Desk 安装不要求修改宿主。
